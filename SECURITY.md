# Security policy

GitHub private vulnerability reporting is **not enabled** for this repository (checked via the GitHub API on 2026-10-15).

To report a vulnerability, please email redevops@redevops.io (the address listed in the GitHub organisation metadata) and avoid
posting exploit details in a public issue. A dedicated security contact, response times and a disclosure policy are
**to be confirmed**; none is promised here.

Maturity note: this repository is labelled **internally reproduced** (see [STATUS.md](STATUS.md)); it has had no formal security audit.
